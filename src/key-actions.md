## 🔹 Line Editing
- **Move line up/down** → `Alt + ↑ / ↓`
- **Copy line up/down** → `Shift + Alt + ↑ / ↓`
- **Delete line** → `Ctrl + Shift + K` (Mac: `Cmd + Shift + K`)
- **Insert line below** → `Ctrl + Enter` (Mac: `Cmd + Enter`)
- **Insert line above** → `Ctrl + Shift + Enter` (Mac: `Cmd + Shift + Enter`)
- **Select current line** → `Ctrl + L` (Mac: `Cmd + L`)
- **Join line below** → `Ctrl + J` (Mac: `Cmd + J`)
- **Duplicate selection/line** → `Shift + Alt + ↓`

## 🔹 Multi-Cursor & Column Editing
- **Add cursor above/below** → `Ctrl + Alt + ↑ / ↓` (Mac: `Option + Cmd + ↑ / ↓`)
- **Add cursor to all occurrences** → `Ctrl + Shift + L` (Mac: `Cmd + Shift + L`)
- **Add next occurrence** → `Ctrl + D` (Mac: `Cmd + D`)
- **Add cursors to line ends** → `Shift + Alt + I`

## 🔹 Indentation & Formatting
- **Indent line** → `Ctrl + ]` (Mac: `Cmd + ]`)
- **Outdent line** → `Ctrl + [` (Mac: `Cmd + [`)
- **Auto format selection/document** → `Shift + Alt + F` (Mac: `Option + Shift + F`)
